## Free hosting
This is a static HTML/CSS/JS site, so it does not need Python or a server.

GitHub Pages is a straightforward free option:
1. Create a GitHub repository.
2. Upload these files.
3. Enable Pages from the repository settings.
4. Your site can use a `github.io` address.

Cloudflare Pages is another free option and can deploy the same static files.
